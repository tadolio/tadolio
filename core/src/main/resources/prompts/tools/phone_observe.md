Look at the phone's current screen (the virtual display). Returns the foreground app, all visible elements, and a compact accessibility tree grouped by window, with parent-child relationships and control states. `elements` supplies targeting data; tree nodes join by ref and use r/b/id/c/t/d/h for role/bounds/resourceId/children/text/description/hintText (see phone format defaults). With a tree, element centers use at:[x,y], omitted when exactly derivable from bounds. Use the tree to identify which item or dialog owns a control, then pass that control's ref and snapshotId to {{tap}}. When the tree is missing much of the screen, treeQuality says so and visibleText adds on-device OCR text with tap centers (a screenshot too, if you can view images); if the target is still missing or ambiguous, request {{screenshot}} or {{find_visually}}.
