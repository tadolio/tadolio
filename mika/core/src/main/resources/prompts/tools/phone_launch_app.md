Open an installed app on the virtual display by exact package name; wait for foreground. For a clone/work-profile copy, pass user from its phone_list_apps entry; omit for main app. cold=true restarts at the initial screen. Check the result: not foreground returns ok:false and the current app; foreground with unreadable window is reported, so do not relaunch. ok:true with chooser means select the user's intended copy, otherwise main; do not relaunch. app_in_use_by_other_task means another task holds it; to wait, call again with wait (seconds), opening when released.
